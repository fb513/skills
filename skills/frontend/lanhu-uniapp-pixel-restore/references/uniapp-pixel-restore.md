# Uniapp Pixel Restore Reference

本参考用于执行蓝湖设计稿到本仓库 uni-app 小程序页面的高保真还原。除仓库内指定的 OSS 上传脚本外，不要把这里的能力描述改写成具体命令、工具调用名或固定环境假设。

## 能力抽象

- 设计读取能力：获取设计列表、指定设计详情、画布尺寸、结构化标注、HTML/CSS、设计截图和 Design Tokens。
- 资源获取能力：获取切图、图标、背景图和下载映射，下载到本地后上传到 OSS，并记录可在项目中使用的稳定 OSS 地址。
- 项目检查能力：读取仓库文件、识别页面结构、组件体系、资源目录、Tailwind token 和现有实现风格。
- 预览能力：在目标小程序环境或等价 H5 环境运行页面。
- 浏览器自动化能力：打开预览页面、设置视口、等待稳定、截图、读取页面尺寸和资源加载状态。
- 视觉核对能力：人工或自动对照设计截图、规格账本和页面截图，发现偏差并归因。

## 规格账本

实现前建立规格账本。账本可以是临时分析记录，也可以是交付说明的一部分；任务复杂、页面元素多或存在设计取舍时，应保留到交付说明中。

| 元素 | 设计来源 | 设计值 | 目标值 | 实现位置 | 验证结果 | 偏差说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 页面背景 | 结构化标注/截图 | 颜色、渐变或图片 | 换算后的样式 | 页面根节点 | 通过/偏差 | 原因 |
| 页面配置 | 设计标题/导航形态/页面背景 | 标题、是否自定义导航、背景色 | `src/pages.json` 中 `navigationBarTitleText` / `navigationStyle` / `backgroundColor` | 页面配置 | 通过/偏差 | 原因 |
| 顶部区域 | 结构化标注 | 高度、间距、字号 | 换算后的 rpx | 页面头部 | 通过/偏差 | 原因 |
| 主卡片 | CSS/标注 | 宽高、圆角、阴影 | token 或精确值 | 对应组件 | 通过/偏差 | 原因 |
| 图片资源 | 切图清单 | 尺寸、裁剪、透明边缘 | OSS 地址和尺寸 | image 节点 | 通过/偏差 | 原因 |

## 单位换算

- 先确认设计画布宽度和目标小程序视觉宽度。
- 以小程序 750rpx 视觉宽度为基准时，换算关系为：目标 rpx 等于设计 px 乘以 750 再除以设计画布宽度。
- 只有设计画布宽度为 375px 时，才可把 `px × 2 = rpx` 当作上述公式的简写；其他画布禁止直接套用 `×2`。
- 在规格账本中记录画布宽度、换算公式和实际比例，例如 `375px -> 750rpx, ratio=2`。
- 字号、行高、间距、圆角、宽高、阴影偏移和模糊半径都按同一画布比例换算，除非平台能力或项目 token 明确要求特殊处理。
- 设计值刚好落在项目 token 上时优先使用 token；关键像素值没有等价 token 时使用换算后的精确值，并记录原因。
- 不要为了得到整数而随意四舍五入。允许为小程序渲染稳定性做极小调整，但必须不改变视觉关系。

## 语义布局推导

- 用坐标判断模块关系，而不是复制坐标：相近的边界、共同背景、同一对齐线、重复尺寸和层级关系通常表示同一模块或列表结构。
- 用业务语义命名和组织结构：页面、头部、筛选、Tab、列表、卡片、按钮、空态、加载态、弹窗、底部操作区。
- 对动态内容预留弹性：长文本换行、多条列表、空数据、加载中、禁用态、选中态、真实图片比例和安全区。
- 对固定格式元素保持稳定尺寸：头像、图标按钮、Tab、状态标签、列表项、底部按钮、图片容器和固定比例区域。
- 定位只能用于有语义的覆盖关系，例如角标、浮层、吸顶区、图片内标记、遮罩和动画层。

## 项目适配

- 实现前读取 `DESIGN.md`、`tailwind.config.js`、`src/styles/design-tokens.scss`，并抽样读取目标页面或同类页面，确认当前视觉规范和代码风格。
- 实现前必须读取 `src/pages.json` 中目标页面配置；还原完成后同步 `navigationBarTitleText`、`navigationStyle`、`backgroundColor` 等页面级配置。
- `navigationBarTitleText` 必须与设计标题或页面内自定义标题一致。页面使用自定义导航栏时，必须配置 `navigationStyle: "custom"`，避免原生导航栏与页面内标题叠加。
- 页面级 `backgroundColor` 必须与设计页面底色一致；不要只改页面根节点样式而漏掉小程序页面配置。
- 使用 Vue 3 Composition API 和 `<script setup lang="ts">`。
- 页面文案和必要注释使用中文。
- 复用现有组件、图标体系、导航封装、请求封装和资源目录约定。
- wot-design-uni 组件按项目自动导入机制使用，不额外手写导入。
- 业务接口、状态管理和导航逻辑保持稳定；除非用户目标要求，不改无关模块。
- Tailwind token 用于常规间距、字号、颜色、圆角和阴影；像素还原专用值仅在必要时写入页面局部样式。
- 颜色、阴影、圆角和字号优先映射到 `var(--fy-*)`、Tailwind token 或既有组件变体。
- 设计关键色没有等价 token 时，先在页面局部定义语义化 CSS 变量，再引用该变量；不要把裸 `#hex` / `rgb(a)` 分散写到多个选择器里。
- 使用 `FyIcon` 时遵守项目限制：`color` prop 不能传 `var(--fy-*)`，必须传 hex 字面量，并在附近注释标注对应 token 来源。

## 资源下载与 OSS 上传

- 所有设计图片、背景图、图标和切图必须先下载到本地，作为上传源文件和视觉核对证据。
- 下载后的切图必须使用本仓库 `scripts/upload-image-to-oss.cjs` 上传到 OSS；不要重写上传流程，也不要手动拼接 OSS 地址。
- 上传脚本未显式传 token 时会自动调用验证码接口和登录接口；执行还原任务时优先使用脚本默认登录能力，除非用户明确提供其他 token 或环境配置。
- 页面和组件代码必须引用上传脚本输出结果中的 OSS `url`，不得引用下载后的本地切图路径。
- 不用远程设计资源、临时链接、Lanhu CDN 地址、占位图、emoji 或临时 SVG 替代真实切图。
- 建立资源映射表，至少记录：设计资源名、本地下载路径、OSS `url`、原始尺寸、使用页面或组件。
- 透明边缘、阴影边缘、圆角裁剪和图片比例必须复查，避免出现断层、白边、阴影线或拉伸变形。

## 预览与截图

- 优先验证目标小程序环境；无法直接截图时，可使用 H5 作为视觉等价检查，但必须说明差异。
- H5 截图需要浏览器自动化能力，不需要设计读取能力配合。
- 浏览器自动化能力至少应能打开预览页、设置设计对应视口、等待首屏稳定、截图并确认关键资源已加载。
- 如果无法截图，必须降级为构建检查、静态样式核对、资源路径核对和人工可复现说明。
- 截图返查应覆盖首屏、滚动区域、长文本、空态、加载态、选中态、禁用态和真实图片比例中与当前任务相关的状态。
- 最低验证顺序：
  1. 运行 `npm run build:mp-weixin`，确认小程序构建通过。
  2. 检查新增切图已经通过 `scripts/upload-image-to-oss.cjs` 上传，并保留本地源文件到 OSS 地址的映射。
  3. 检查代码中的新增切图引用均为脚本输出的 OSS `url`，没有引用下载后的本地切图路径。
  4. 检查 `src/pages.json` 中目标页面 `navigationBarTitleText`、`navigationStyle`、`backgroundColor` 与设计标题、导航形态和页面底色一致。
  5. 搜索确认没有残留远程设计资源链接、Lanhu CDN 地址、临时占位图、emoji 或临时 SVG。
  6. 浏览器自动化能力可用时，运行 H5 预览并截图返查关键状态。
  7. 代码修改完成后运行 `graphify update .`。

## 偏差归因

发现偏差时先判断来源：

- 规格提取错误：设计值、画布宽度、资源尺寸或状态理解错误。
- 单位换算错误：px 到 rpx 比例、字号、行高或阴影换算错误。
- 结构判断错误：把装饰当模块、把模块当图片、把浮层当普通流式元素。
- 组件默认样式干扰：内置 padding、line-height、border、font-weight、overflow 或背景影响还原。
- 页面配置遗漏：`src/pages.json` 的 `navigationBarTitleText`、`navigationStyle` 或 `backgroundColor` 未同步，导致标题、原生导航栏或页面底色与设计不一致。
- 图片资源错误：上传源文件、OSS 地址、透明边缘、阴影、圆角、object-fit、尺寸比例或导出切图边界错误。
- 动态内容问题：长文本、列表数量、真实图片比例、安全区或滚动容器导致布局漂移。
- 平台差异：H5 与小程序在字体、行高、滚动、图片加载和安全区上的渲染差异。

修正后只要影响了视觉关系，就重新验证相关规格账本项。

交付时简明说明：

- 已实现的页面或组件。
- 已上传 OSS 的关键资源及引用方式。
- 已完成的验证方式。
- 未完成的截图、预览或平台验证项。
- 与设计稿不完全一致的取舍及原因。
- 剩余风险。
