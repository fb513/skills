# Uniapp Pixel Restore Reference

本参考用于执行蓝湖设计稿到本仓库 uni-app 小程序页面的高保真还原。实现优先依据结构化设计规格、项目代码、设计 token 和可追溯换算结果；微信小程序截图是工作结束前的验证手段，不作为实现前反推页面的主要依据。除仓库内指定的 OSS 上传脚本、已有微信小程序 E2E 自动化能力外，不要把这里的能力描述改写成其他具体命令、工具调用名或固定环境假设。

## 能力抽象

- 设计读取能力：获取设计列表、指定设计详情、画布尺寸、结构化标注、HTML/CSS、设计截图和 Design Tokens。
- 资源获取能力：获取切图、图标、背景图和下载映射，下载到本地后上传到 OSS，并记录可在项目中使用的稳定 OSS 地址。
- 项目检查能力：读取仓库文件、识别页面结构、组件体系、资源目录、Tailwind token、CSS 变量、`FyIcon` 映射和现有实现风格。
- 小程序预览能力：在微信小程序环境运行页面，优先复用仓库已有 E2E 自动化打开、路由进入、状态等待和截图能力。
- 小程序自动化能力：打开构建后的 `mp-weixin` 产物、进入目标页面、等待稳定、截图、读取页面状态和关键资源加载状态。
- 视觉核对能力：在代码实现和静态核对完成后，对照设计截图、规格账本和小程序页面截图，发现偏差并归因。

## 执行前检查

实现前先做 preflight，发现缺失能力时立即记录降级方案，不要等到交付阶段才暴露。

| 检查项 | 必须确认 | 失败处理 |
| --- | --- | --- |
| 设计读取 | 能取得画布尺寸、结构化标注、设计截图和切图清单 | 说明缺失项，不能凭截图或记忆还原关键值 |
| 目标页面 | 目标 `.vue`、同类页面、`src/pages.json` 配置可读取 | 先定位路由和页面配置，再改代码 |
| 项目规范 | `DESIGN.md`、`tailwind.config.js`、`src/styles/design-tokens.scss` 可读取 | 缺失时说明 token 映射风险 |
| 资源上传 | `scripts/upload-image-to-oss.cjs` 存在且能执行 | 不能上传时不得把本地切图或设计 CDN 写入最终代码 |
| 小程序 E2E | 构建、打开、路由进入、截图链路可用 | 记录阻塞点，降级为构建检查、静态核对和人工步骤 |

| --- | --- | --- | --- | --- | --- | --- | --- |

| 页面背景 | 结构化标注/截图 | 颜色、渐变或图片 | token 或局部变量 | 换算后的样式 | 页面根节点/pages.json | 通过/偏差 | 原因 |
| 页面配置 | 设计标题/导航形态/页面背景 | 标题、是否自定义导航、背景色 | 对齐页面配置字段 | `navigationBarTitleText` / `navigationStyle` / `backgroundColor` | `src/pages.json` | 通过/偏差 | 原因 |

## 单位换算

- 先确认设计画布宽度和目标小程序视觉宽度。
- 以小程序 750rpx 视觉宽度为基准时，换算关系为：目标 rpx 等于设计 px 乘以 750 再除以设计画布宽度。
- 只有设计画布宽度为 375px 时，才可把 `px × 2 = rpx` 当作上述公式的简写；其他画布禁止直接套用 `×2`。
- 在规格账本中记录画布宽度、换算公式和实际比例，例如 `375px -> 750rpx, ratio=2`。
- 字号、行高、间距、圆角、宽高、边框宽度、阴影偏移、阴影模糊半径、阴影扩散和图片裁剪都按同一画布比例换算，除非平台能力或项目 token 明确要求特殊处理。
- 文字行高如果设计给出 px，按比例换算为 rpx；如果设计给出百分比或倍数，优先保留倍数关系，并记录对应的实际 rpx 结果。
- 阴影必须记录 `x/y/blur/spread/color`；小程序或 CSS 能力不支持的 spread 等值要说明平台适配方式。
- 图片必须记录设计容器尺寸、原始切图尺寸、`mode`/`object-fit`、圆角裁剪和透明边缘；不得只写 URL。
- 设计值刚好落在项目 token 上时优先使用 token；关键像素值没有等价 token 时使用换算后的精确值，并记录原因。
- 不要为了得到整数而随意四舍五入。允许为小程序渲染稳定性做极小调整，但必须记录设计值、计算值、最终值和调整原因。

## 语义布局推导

- 用坐标判断模块关系，而不是复制坐标：相近的边界、共同背景、同一对齐线、重复尺寸和层级关系通常表示同一模块或列表结构。
- 用业务语义命名和组织结构：页面、头部、筛选、Tab、列表、卡片、按钮、空态、加载态、弹窗、底部操作区。
- 对动态内容预留弹性：长文本换行、多条列表、空数据、加载中、禁用态、选中态、真实图片比例和安全区。
- 对固定格式元素保持稳定尺寸：头像、图标按钮、Tab、状态标签、列表项、底部按钮、图片容器和固定比例区域。
- 定位只能用于有语义的覆盖关系，例如角标、浮层、吸顶区、图片内标记、遮罩和动画层。

## 项目适配

- 实现前读取 `DESIGN.md`、`tailwind.config.js`、`src/styles/design-tokens.scss`，并抽样读取目标页面或同类页面，确认当前视觉规范和代码风格。
- 实现前必须读取 `src/pages.json` 中目标页面配置；还原完成后同步 `navigationBarTitleText`、`navigationStyle`、`backgroundColor` 等页面级配置。
- `navigationBarTitleText` 必须与设计标题或页面内自定义标题一致。页面使用自定义导航栏时，必须配置 `navigationStyle: "custom"`，避免原生导航栏与页面内标题叠加。
- 页面级 `backgroundColor` 必须与设计页面底色一致；不要只改页面根节点样式而漏掉小程序页面配置。
- 使用 Vue 3 Composition API 和 `<script setup lang="ts">`。
- 页面文案和必要注释使用中文。
- 复用现有组件、图标体系、导航封装、请求封装和资源目录约定。
- wot-design-uni 组件按项目自动导入机制使用，不额外手写导入。
- 业务接口、状态管理和导航逻辑保持稳定；除非用户目标要求，不改无关模块。
- Tailwind token 用于常规间距、字号、颜色、圆角和阴影；像素还原专用值仅在必要时写入页面局部样式。
- 颜色、阴影、圆角和字号优先映射到 `var(--fy-*)`、Tailwind token 或既有组件变体。
- 设计关键色没有等价 token 时，先在页面局部定义语义化 CSS 变量，再引用该变量；不要把裸 `#hex` / `rgb(a)` 分散写到多个选择器里。
- 使用 `FyIcon` 时，可以传入 `src/components/FyIcon.vue` 中 `COLOR_TOKEN_VALUES` 已支持的 `var(--fy-*)`；使用前必须核对该映射与 `src/styles/design-tokens.scss` 的实际 token 值一致。
- `FyIcon` 需要使用未映射 token 时，优先补齐 `COLOR_TOKEN_VALUES` 映射；如果只在局部使用 hex，必须在附近注释标注对应 token 或设计来源。不得把未映射 CSS 变量直接传入 SVG data URL。

## 资源下载与 OSS 上传

- 所有设计图片、背景图、独有图标和切图必须先下载到本地，作为上传源文件和视觉核对证据。
- 下载后的设计专属位图、照片、插画、复杂背景和无法用项目资源高保真表达的图标，必须使用本仓库 `scripts/upload-image-to-oss.cjs` 上传到 OSS；不要重写上传流程，也不要手动拼接 OSS 地址。
- 上传脚本未显式传 token 时会自动调用验证码接口和登录接口；执行还原任务时优先使用脚本默认登录能力，除非用户明确提供其他 token 或环境配置。
- 页面和组件代码必须引用上传脚本输出结果中的 OSS `url`，不得引用下载后的本地切图路径。
- 简单语义图标优先检查 `FyIcon` 是否已有同义图标；项目既有稳定资源能与设计含义和视觉规格对齐时可复用，但必须在规格账本记录替代依据。
- 简单纯色、渐变、圆角、阴影、分割线和几何背景能用 CSS 按设计值实现时，不应导出为图片。
- 不用远程设计资源、临时链接、Lanhu CDN 地址、占位图、emoji 或临时 SVG 替代真实切图。
- 建立资源映射表，至少记录：设计资源名、本地下载路径、OSS `url` 或项目复用资源、原始尺寸、目标显示尺寸、使用页面或组件、替代依据。
- 透明边缘、阴影边缘、圆角裁剪和图片比例必须复查，避免出现断层、白边、阴影线或拉伸变形。

## 预览与截图

- 默认验证微信小程序环境；截图是代码实现、静态核对和构建检查完成后的收尾返查，不是页面实现前的主要输入。
- 小程序截图需要微信开发者工具自动化能力，不需要设计读取能力配合。
- 小程序自动化能力至少应能打开构建后的 `mp-weixin` 产物、进入目标页面、等待首屏稳定、截图并确认关键资源已加载。
- 先完成代码层核对：页面配置、资源引用、token/FyIcon 映射、设计值换算、无设计 CDN、无本地切图路径、无导出绝对定位骨架。
- 普通小程序构建检查使用 `npm run build:mp-weixin`；截图链路需要 E2E 自动化产物，使用 `npm run build:e2e:mp-weixin` 生成带运行时自动化元数据的构建。
- 优先使用仓库现有的 E2E 构建、自动化打开、路由进入和截图脚本；截图脚本应等待目标页关键 selector，生成 `tests/e2e/artifacts/` 下的 PNG 文件，并在文件不存在或大小为 0 时失败。
- 推荐收尾截图链路：`npm run build:e2e:mp-weixin` -> `npm run test:e2e:mp-weixin:open` -> 必要时执行登录或 connect 脚本 -> `npm run test:e2e:mp-weixin:capture -- /目标页面路径 截图名称 --selector .关键元素`。需要验证交互状态时，可追加 `--tap .操作元素` 后再截图。
- 截图返查必须实际打开生成的 PNG 进行视觉检查；仅验证当前路由、页面栈、DOM 元素或按钮文案，只能作为截图前置检查，不能替代截图结论。
- 如果截图第一次失败，先关闭或重开微信开发者工具自动化会话后重试一次，再判断是否降级；重试记录应区分是 E2E 构建产物、自动化端口、登录态、路由、关键元素等待还是截图落盘失败。
- 如果无法执行小程序自动化截图，必须降级为构建检查、静态样式核对、资源路径核对和人工可复现的小程序验收说明，并明确阻塞原因。
- 截图返查应覆盖首屏、滚动区域、长文本、空态、加载态、选中态、禁用态和真实图片比例中与当前任务相关的状态。
- 最低验证顺序：
  1. 运行 `npm run build:mp-weixin`，确认普通小程序构建通过。
  2. 检查 `src/pages.json` 中目标页面 `navigationBarTitleText`、`navigationStyle`、`backgroundColor` 与设计标题、导航形态和页面底色一致。
  3. 检查规格账本中的关键设计值已经完成换算，并能追溯到代码实现位置。
  4. 检查新增切图已经通过 `scripts/upload-image-to-oss.cjs` 上传，或已记录复用 `FyIcon`/项目资源的依据。
  5. 检查代码中的新增设计资源引用均为脚本输出的 OSS `url` 或项目既有稳定资源，没有引用下载后的本地切图路径。
  6. 搜索确认没有残留远程设计资源链接、Lanhu CDN 地址、临时占位图、emoji 或临时 SVG。
  7. 检查 `FyIcon` 使用的 token 映射与 `src/styles/design-tokens.scss` 一致。
  8. 运行微信小程序 E2E 自动化预览并截图返查关键状态。
  9. 代码修改完成后运行 `graphify update .`。

## 偏差归因

发现偏差时先判断来源：

- 规格提取错误：设计值、画布宽度、资源尺寸或状态理解错误。
- 单位换算错误：px 到 rpx 比例、字号、行高或阴影换算错误。
- 结构判断错误：把装饰当模块、把模块当图片、把浮层当普通流式元素。
- 组件默认样式干扰：内置 padding、line-height、border、font-weight、overflow 或背景影响还原。
- 页面配置遗漏：`src/pages.json` 的 `navigationBarTitleText`、`navigationStyle` 或 `backgroundColor` 未同步，导致标题、原生导航栏或页面底色与设计不一致。
- 图片资源错误：上传源文件、OSS 地址、透明边缘、阴影、圆角、object-fit、尺寸比例或导出切图边界错误。
- 图标映射错误：`FyIcon` 颜色 token 未映射、映射值过期，或用切图替代了已有语义图标但未记录依据。
- 动态内容问题：长文本、列表数量、真实图片比例、安全区或滚动容器导致布局漂移。
- 平台差异：微信开发者工具模拟器、真机和 H5 在字体、行高、滚动、图片加载和安全区上的渲染差异；H5 只能作为辅助风险证据。

修正后只要影响了视觉关系，就重新验证相关规格账本项。

## 交付说明

交付时使用固定结构简明说明：

- 实现范围：已实现的页面或组件，以及是否同步 `src/pages.json`。
- 设计证据：画布宽度、换算比例、关键规格来源。
- 资源映射：已上传 OSS 的关键资源、复用项目资源的依据和引用方式。
- 静态核对：页面配置、token/FyIcon 映射、资源引用、无设计 CDN/本地切图路径的检查结果。
- 验证方式：构建命令、小程序 E2E 截图产物、人工复查结论。
- 未完成项：未完成的截图、预览或平台验证项及具体阻塞原因。
- 设计取舍：与设计稿不完全一致的取舍及原因。
- 剩余风险：需要真机或业务数据进一步确认的风险。
