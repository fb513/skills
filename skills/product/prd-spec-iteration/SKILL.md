# PRD / Spec 迭代初始化器

负责创建本次需求的需求目录，并问清这次是历史需求的调整还是一个全新的需求（据此决定要不要把原型复制一份过来）。这个判断由人做：本 Skill 按 `AGENTS.md` 里已有的概况判断这次最像哪一轮，把它写进问句；判不出来就问开放问题，不替人拿主意。

## 具体工作

### A. 项目级（幂等）

1. 检查当前目录根目录 `AGENTS.md`：
   - **不存在** → 按 [`references/agents-template.md`](references/agents-template.md) 实例化。
   - **已存在** → 校验两件事：文件可读、含「流程」标题。不重写、不重排；需要记东西就在需求目录表末尾追加（第 9 步）。
2. 校验失败或文件损坏时报告并停止，不自行重建——重建会把团队写进去的约定冲掉。

### B. 需求级（新建）

**本 Skill 只负责开新一轮，不在已有目录上改，也不判断已有文档处于什么状态。**「像不像某一轮」只看 `AGENTS.md` 的概况，不翻历史目录里的文档。

3. **确定名称**：从产品这次的话里提取，例如「做订单批量导出」→ `订单批量导出`。提取不到时问一句「这一轮需求叫什么名字？」，不要猜，不要用 `untitled`。
4. **确定编号**：glob `[0-9][0-9][0-9][0-9]-*`，按数字取最大值 +1；一个都没有则为 `0001`。算出的编号已有同号目录时说明扫描不完整，报告并停止，不要凑出第二个同号目录。
5. **问清楚这一轮是什么。先判断，再问，最后才建目录。**

   **先判断像哪一轮**：根据产品的描述和「需求目录」表，判断这一轮是全新的需求还是历史需求调整。

   | 这次的说法 | 判断 | 怎么问 |
   |---|---|---|
   | 点名了某轮的编号或名称 | 就是那一轮 | 句子里写那一轮 |
   | 说的是某轮已有的业务、页面或主线 | 最像那一轮 | 句子里写那一轮 |
   | 全新 / 独立 / 另一条线 / 跟哪个都没关系 / 只复用登录 | 像全新需求 | 按全新问，不硬凑一轮 |
   | 只有一个功能名，和表里哪一轮都对不上 | 判不出来 | 开放式问，不给默认值 |

   **判出来了**，把判断写进问句里。产品说「题库那边也要能批量改」，比下来落 0002：

   > 这一轮是在 `0002-题库管理` 上调整，还是一条全新的需求？

   **判不出来**，就把选择权完整交回去：

   > 这一轮是一条全新的需求，还是基于之前某一轮调整？如果是调整，基于哪一轮？

   先判断再问，是因为问句越具体，产品越容易一句话答完。但判断只负责组织问句，不替人定答案：猜错了比开放式提问贵——产品得先纠正你，才轮到说正事。

   | 回答 | 需求目录表的「基于」列 | 接下来 |
   |---|---|---|
   | 全新的需求 | `—` | 建目录，不复制原型 |
   | 在某一轮上调整（含产品把问句里的那一轮改成别的） | 那一轮的编号 | 建目录，从该轮复制原型 |
   | 还没定 | — | **不建目录**，说明原因后结束 |

   **答「还没定」就停在这里，一个目录都不建。** 告诉产品「等定了是新的、还是在哪一轮上改，再来开这一轮」——不是拒绝，是省掉一次返工。

   首轮（没有更早的轮次）必然是 `independent`，不用问。

6. 创建 `<编号>-<名称>/` 目录。
7. **如果是在之前的需求上进行调整，需要复制原型**。之前需求目录里有 `prototype.html` 就整份复制进来，没有就跳过、报告里说明。
8. **在 `AGENTS.md` 的「需求目录」表末尾追加一行**：编号、名称、基于（`—` 或四位编号）、简介（这一轮的概况：做什么，从产品说的话里取，别加工成需求表述，不超过 30 字）。简介就是第 5 步判断后续需求像不像这一轮的唯一依据，写成一个标签等于让下一轮只能瞎猜。
9. 写入 `change-summary.md` 占位。

### 名称规则

- 直接用中文，不做拼音或 kebab-case 转换。编号前缀已保证唯一。
- 文件系统非法字符 `/ \ : * ? " < > |` 替换为 `-`；去掉首尾空格，连续空格压成一个。
- 20 字以内，过长取前 20 字并在报告里说明截断。

## 编号规则

- 四位补零：`0001`、`0002`…`0010`。
- 目录名 `<四位编号>-<中文需求名称>`，中间用半角连字符。
- 编号与名称一经创建都不改写。名称要改就改 PRD 标题，目录不动。
- 已存在的需求目录不覆盖、不改写。编号永不复用。

## 输出约束

- UTF-8 编码，目录名使用中文。
- 不写产品内容，不判断范围、优先级或验收标准。
- 答「还没定」时不建目录、不写任何占位文件。宁可不留痕，也不留一个说不清来历的空目录。
- 不覆盖任何已存在的需求目录。
- 复制原型时整份复制，不改名、不裁剪、不替换内容；之前的需求目录一个字节都不动。
