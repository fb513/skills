# A股行业筛选参考

## 指标与口径

| 主题 | 优先指标 | 使用提示 |
|---|---|---|
| 需求 | 终端销量/用户数、渗透率、复购率、出口/内需、库存 | 区分终端需求与渠道压货、补贴透支；拆分量价 |
| 竞争 | CR3/CR5、龙头份额、产能增速、产品价差、退出数量 | 集中度高不自动等于好行业；验证供给纪律 |
| 壁垒 | 毛利率稳定性、客户留存/转换成本、研发效率、单位成本、牌照/渠道 | 壁垒必须体现为可持续资本回报或现金流 |
| 盈利 | ROE、ROIC、毛利率、营业利润率、利润波动 | 拆解杠杆；周期行业使用正常化利润 |
| 现金流 | 经营现金流/净利润、自由现金流、周转率、资本开支/折旧 | 查明营运资本和扩张性投入对现金的占用 |
| 资产负债 | 净负债/EBITDA、利息覆盖、短债/现金、或有负债 | 在需求下降和融资收紧情景下压力测试 |
| 议价权 | 提价、成本转嫁、应付/应收账期、原料占比 | 使用实际量价和账期结果，不采用宣传口号 |
| 利润池与资本强度 | 利润池分配、资本开支/收入、维护性资本开支、正常化ROIC | 区分行业增长与股东回报 |
| 估值 | PE/PB/EV/EBITDA、股息率、FCF收益率、历史分位数 | 配合正常化盈利、增长、利率和同行使用 |

## 特殊行业调整

- **周期行业**：覆盖价格、销量、库存、产能利用率、资本开支和利润率的完整周期；用跨周期中位数、平均值或供需恢复后的合理利润率估算正常化盈利。
- **银行、保险、券商**：侧重资产质量、资本充足率、负债成本、拨备、ROE和监管周期。
- **高研发或平台行业**：检查研发资本化、获客与留存、网络效应、自由现金流、反垄断和数据监管。
- **公用事业和高股息行业**：检查监管定价、资本开支、负债和分红可持续性；高股息可能来自盈利下滑预期。

## 能力圈与预期差检查

- 能否解释客户、供需、利润池、周期、监管和3—7个价值驱动指标？
- 当前市场的乐观/悲观共识是什么？价格隐含何种需求、利润率和持续时间？
- 反方观点有哪些可验证证据？悲观因素是否永久损害利润池？
- 哪些新事实会改变行业质量或当前机会状态？

## 数据来源优先级

1. 交易所公告、上市公司定期报告和审计报告；
2. 国家统计局、海关、央行及相关监管部门；
3. 行业协会、指数编制方和公开产销量/价格数据；
4. 可靠行情数据库；
5. 券商研报、媒体和访谈，仅作线索并回到原始来源核实。

记录发布日期、数据期间、单位、样本、是否合并、是否经审计以及链接或文件名。
