# A股价值投资门槛与交接协议

## 共同门槛

| 门槛 | 通过条件 | 未通过处理 |
|---|---|---|
| 能力圈 | 能解释客户、利润池、现金流、资本需求和失败路径，并能持续跟踪 | 学习、观察或停止 |
| 行业质量 | 需求耐久、竞争和利润池可解释、长期资本回报合理、永久性风险可控 | 观察或排除 |
| 公司质量 | 价值来源有证据、治理可信、资产负债表可承压、利润能转化为现金 | 补充研究或排除 |
| 价格 | 正常化价值下存在安全边际，悲观情景可承受 | 等待，不用仓位弥补价格 |
| 组合适配 | 集中度、共同风险、流动性和用户承受能力均合格 | 降低上限或不纳入 |
| 可复盘 | 保存原始事实、假设、估值、反方观点、失效条件和交易记录 | 不执行交易 |

总分不能覆盖硬门槛。治理失信、持续经营存疑、无法验证的数据或不可承受的永久性损失风险，应直接触发退回或停止。

## 所有者视角检查

- 将预期回报拆成企业经营增值、分红/回购、股份稀释和估值变化；不要以寻找更高价接手者作为核心逻辑。
- 使用正常化所有者收益：从经营收益中扣除维持竞争力所需的资本开支和正常营运资本需求，并把扩张性投入单列。
- 验证经济商誉和再投资跑道：企业凭什么持续获得超额回报，留存利润还能以多高回报投入多久。
- 分开记录价格变化与企业价值变化；只有改变未来现金流、竞争优势、资本配置或治理的事实才改变价值判断。

## 交易前最小检查

以下问题任一没有证据支持时，停止执行并回到相应研究阶段：

1. 是否能解释生意、现金流、资本需求和主要失败路径？
2. 行业质量、公司质量、价格和组合适配是否分别通过？
3. 当前价格隐含的增长、利润率和持续时间是否可接受？
4. 悲观情景下是否能生存，资产负债表和流动性是否足够？
5. 是否保存原始研究、反方观点、失效条件、仓位上限和复核日？

## 逆向思考六问

1. 市场最普遍的观点是什么？
2. 当前价格隐含怎样的增长、利润率、资本回报和持续时间？
3. 市场可能错在哪里，证据和反证分别是什么？
4. 悲观因素是暂时、周期性还是永久性？
5. 哪些事实会证明自己的判断错误？
6. 判断错误时，安全边际、资产负债表和仓位上限能否防止永久性损失？

## 阶段扩展字段

### 行业研究

- 行业分类、样本范围和周期覆盖；
- 行业质量分及评分置信度；
- 估值/周期机会状态；
- 利润池、资本强度和优先公司类型。

### 公司研究

- 一句话生意和核心价值来源；
- 经济商誉、账面商誉风险和再投资跑道；
- 正常化盈利、所有者收益和三情景估值；
- 公司研究状态；不要在本阶段决定最终仓位。

### 组合管理

- 组合目标、已有资产、流动性和风险约束；
- 组合角色、权重区间与上限、共同风险因子；
- 建仓、加仓、暂停、减仓和退出条件；
- 交易记录和现金缓冲。

### 投资复盘

- 原始假设与最新事实对照；
- 企业价值变化、价格变化和收益归因；
- 分析、估值、组合、执行、流程和认知错误；
- 回写阶段、改进动作和验证日期。
