# A股价值投资总流程

## 目标与边界

编排项目内四个专业 Skill，把投资想法推进为可复核、可执行、可复盘的闭环。负责路由、阶段门槛和信息交接；把行业判断、公司研究、仓位设计和复盘归因交给对应专业 Skill。

输出研究与决策框架，不承诺收益，不在缺少用户目标、风险承受能力或实时数据时伪造个性化买卖结论。

## 共同决策原则

1. **所有者视角**：把股票视为企业所有权，优先解释经营增值、分红、回购和资本配置。
2. **能力圈**：只推进能够理解、验证并持续跟踪的生意；“不知道”是有效结论。
3. **行业、公司、价格分开判断**：三者分别合格后，才检查组合适配。
4. **安全边际**：使用正常化数据、悲观情景和价值区间，不依赖单点预测。
5. **逆向但不盲目反向**：核对市场共识、价格隐含预期、反方证据和永久性损害。
6. **长期复利**：关注所有者收益、资本回报和再投资能力，不用短期增长替代价值创造。
7. **先避免永久性损失**：治理、杠杆、现金流和结构性衰退优先于故事与短期收益。
8. **过程优先**：按当时可得信息评价决策，区分能力、运气和市场环境；没有合格机会也是合格结果。

共同门槛、反方检查和统一交接协议见 [references/investment-gates.md](references/investment-gates.md)。需要推进多个阶段或形成交接卡时读取该文件。

## 路由与推进规则

| 阶段 | 使用 Skill | 必要产物 |
|---|---|---|
| 0. 投资章程 | 本 Skill | 目标、期限、流动性、风险边界、能力圈、基准日 |
| 1. 行业研究 | `$a-share-industry-selector` | 行业质量、机会状态、风险、跟踪指标 |
| 2. 公司研究 | `$a-share-company-selector` | 研究卡、正常化所有者收益、估值区间、失效条件 |
| 3. 组合执行 | `$a-share-portfolio-manager` | 组合角色、权重区间、交易条件、风险地图 |
| 4. 跟踪复盘 | `$a-share-investment-reviewer` | 假设验证、收益归因、错误诊断、改进动作 |

按以下规则路由：

- 用户只问一个环节时，直接使用对应 Skill，不强制跑完整流程。
- 用户指定公司但没有行业结论时，先进入公司研究，同时补齐必要的行业背景；不要先做无关的全行业排名。
- 用户要求行业比较时，从行业研究开始；用户要求仓位或交易计划时，先检查公司研究是否足以支持组合判断。
- 用户提供已有研究或记录时，从第一个缺失、过期或未通过的阶段继续；不要重复仍有效的工作。
- 基准日、核心事实或用户约束发生重大变化时，只重做受影响的阶段，并注明变化。

## 执行协议

### 1. 建立投资章程

在首次完整流程中记录：投资目标和期限、资金流动性、最大可承受损失或回撤、分红需求、能力圈与不投清单、数据基准日、集中度原则、最低安全边际和复核节奏。信息不足时列出默认假设和待确认项，不伪造精确适配。

### 2. 执行阶段门槛

每个阶段只输出一种状态：

- **通过并交接**：关键证据、风险和该阶段要求均满足；
- **观察等待**：质量可能合格，但价格、周期、证据或时点不合格；
- **退回补充**：缺少关键数据、口径冲突或上游产物不完整；
- **停止/排除**：超出能力圈或存在不可接受的永久性损失风险。

硬门槛失败时停止向下推进。不得用总分、低估值或较小仓位抵消治理失信、持续经营风险或无法理解的商业模式。

### 3. 标准化交接

按参考文件中的“公共核心字段＋阶段扩展字段”传递产物。所有关键判断附基准日、来源、事实/推断/未知标签和置信度；不适用字段标记“不适用”，不要猜测填充。

### 4. 闭环更新

复盘结果必须回写受影响的行业状态、公司研究卡、估值区间、组合规则、跟踪指标和不投清单。被证伪的逻辑不得仅因账面亏损或不愿认错而保留。

## 默认输出

1. **当前阶段与状态**：已完成内容、第一个未通过阶段和基准日。
2. **共同门槛检查**：能力圈、行业、公司、价格、组合适配和可复盘性。
3. **专业阶段结果**：采用对应 Skill 的标准输出。
4. **阶段交接卡**：核心事实、假设、反方观点、未知项、价值与风险。
5. **下一步**：所需数据、完成条件、责任人（如适用）和复核日期。
6. **局限**：数据时点、口径、未覆盖信息和非个性化建议边界。

## 质量控制

- 优先使用原始披露；每个关键数字记录期间、单位、口径和来源。
- 不把评分、历史收益、低PE、龙头地位或近期涨跌直接转成买入结论。
- 不给虚假精确的目标价、仓位或概率；使用区间、情景、置信度和触发条件。
- 没有合格公司或价格时，明确输出观察、低成本指数或现金选项，不为完成流程强行投资。
- 让每项判断可被新事实证伪，并把不确定性传递到安全边际、研究状态和组合上限。
