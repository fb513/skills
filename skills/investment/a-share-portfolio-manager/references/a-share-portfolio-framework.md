# A股组合管理参考

## 组合检查表

| 项目 | 需要回答的问题 |
|---|---|
| 目标 | 长期增值、现金流、抗通胀还是综合目标？ |
| 期限 | 资金多久不会使用，能否承受多年低迷？ |
| 风险 | 最大可接受回撤、永久损失和流动性压力是什么？ |
| 能力圈 | 是否能读懂并持续跟踪每家公司？ |
| 集中度 | 公司、行业、产业链和共同风险因子是否超限？ |
| 估值 | 每个仓位的正常化价值区间和安全边际是什么？ |
| 回报来源 | 经营增值、分红/回购还是估值扩张？ |
| 现金 | 是否保留应急资金和机会资金？ |
| 退出 | 哪些事实证伪逻辑，什么价格使未来回报不足？ |

## 永久性损失检查

- 是否超出能力圈或依赖无法验证的单一预测？
- 是否把周期高点利润、补贴或热门叙事当成长期价值？
- 公司是否可能因杠杆、再融资、治理或技术替代永久受损？
- 当前价格是否反映过度乐观假设，悲观情景下是否仍有安全边际？
- 持仓是否表面分散但共同暴露于同一政策、客户、商品或融资风险？
- 加仓理由是否是基本面变强和赔率改善，而非单纯下跌或锚定成本？

## 权重框架（示例，不是固定规则）

- **核心**：较高但有上限；需要清晰优势、可信治理、稳定现金流和合理估值。
- **卫星**：较低权重；适用于成长、周期或反转，要求更高证据和更严格止错。
- **观察**：不计入核心组合，等待价格、安全边际或关键事实改善。
- **现金**：覆盖已知需求并保留估值显著改善时的行动空间。

用“区间＋上限”，并结合用户目标、已有资产和风险承受能力确认。

## 风险地图

按共同风险因子重分类，而不只按股票代码统计：

- 宏观和利率；
- 政策、监管和补贴；
- 商品价格、汇率和出口；
- 地产、基建或消费周期；
- 相同客户、供应商、技术路线或融资渠道；
- 大股东、管理层和治理风险。

若多个行业同时受同一风险因子影响，应合并计算暴露并降低组合风险。
