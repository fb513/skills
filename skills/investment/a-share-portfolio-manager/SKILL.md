# A股组合管理器

## 目标与边界

把已经完成的行业和公司研究转化为组合方案和交易纪律，不替用户做未经授权的个性化交易决定。输出区间、条件、风险边界和待确认假设；缺少资产规模、期限、流动性或风险承受能力时，使用示例并明确不能直接执行。

组合执行有四个独立门槛：能力圈、行业质量、公司质量、价格安全边际；通过后还要检查组合适配。组合 Skill 负责仓位和相关性，不重做上游公司的完整研究。

## 工作流程

### 1. 明确组合任务

记录投资目标、期限、可投资资产区间、现金需求、最大可接受回撤、分红需求、已有持仓、税费/交易限制、能力圈和排除项。信息缺失时列出假设与需确认问题。

### 2. 建立可投资清单

- 只把已通过行业和公司门槛的标的纳入候选组合；研究不完整、价格不合格或数据过期的标记为观察名单。
- 为每家公司记录质量状态、正常化所有者收益、合理价值区间、价格日期、核心假设、永久性风险和失效条件。
- 排除治理/审计硬伤、悲观情景无法承受、超出能力圈或没有安全边际的标的。

### 3. 设计组合结构

先决定组合角色，再决定个股：

- **核心**：生意易懂、优势和治理可信、现金流稳定、价格合理；
- **卫星**：成长、周期、反转或特殊机会，证据要求更高、上限更低；
- **观察**：等待价格、周期或关键事实，不计入核心仓位；
- **现金/低风险资产**：覆盖已知资金需求并保留估值改善时的选择权。

按公司、行业、产业链和共同风险因子同时设上限。不要用股票数量制造虚假分散；新增持仓必须有明确的边际价值。

### 4. 制定仓位方法

仓位由公司质量、估值安全边际、基本面确定性、流动性、下行风险和组合相关性共同决定。采用“角色＋权重区间＋硬上限”，而不是虚假精确的单点比例。

至少写清：

- 单一公司、行业和共同风险的上限；
- 初始仓位、加仓上限和升级条件；
- 估值过高、逻辑变化、集中度超限时的减仓条件；
- 现金最低比例和流动性缓冲；
- 新资金优先级及避免频繁换手的原则。

评分不能直接转换仓位，摊低成本不能替代重新研究。

可将区间标记为核心、标准、试错或观察，但每一档都要写升级、降级和暂停条件；标签本身不决定权重。

### 5. 制定买入与加仓计划

每家公司形成交易卡，至少包含买入理由、三项核心假设、价值区间、悲观价值、安全边际、建仓区间、分批节奏、单次/总仓位上限、暂停条件和复核日期。

交易前检查：即使没有更高价接手者，是否仍愿意依靠企业经营持有？回报主要来自经营、分红/回购还是估值扩张？所有者收益和再投资跑道是否支持价格？价格下跌本身不是加仓理由。

只有基本面得到新证据验证、价格仍有安全边际、共同风险未超限时才加仓。分批买入是控制执行风险的工具，不能替代估值纪律。

逆向交易还要写市场共识、已反映的风险、可能永久损害价值的风险和退出触发条件。

### 6. 建立卖出和止错规则

- **逻辑卖出**：收入、竞争优势、现金流、治理或行业结构发生永久性恶化；
- **估值卖出**：价格显著超过价值区间，未来回报不足；
- **组合卖出**：共同风险过高、仓位超限或出现风险更低且赔率更好的替代品。

写明证据、观察期限和动作，并为“暂停买入、降级、减仓、退出”设置不同阈值。不要因单日波动或短期亏损自动卖出，也不要因沉没成本拒绝承认错误。技术性风控只能保护流动性和极端风险，不能替代基本面判断。

### 7. 记录、执行和监控

每笔交易记录日期、价格、数量、费用、仓位、理由、估值、假设、风险和复核日；交易后更新权重和现金。

下单前再次检查：研究和价格是否在有效期内、是否仍在能力圈、是否存在未解决红旗、交易后公司/行业/共同风险是否超限。任一项不合格时暂停执行并记录缺口。

每家公司只保留3—7项真正影响价值的指标，记录来源、频率、正常区间、预警阈值和动作。没有合格价格时，正式输出观察、指数或现金选项，不为维持满仓强行买入。

## 默认输出

1. **组合目标与假设**：期限、风险、流动性、已有持仓和数据基准日。
2. **组合方案表**：标的/行业、角色、质量状态、价值区间、权重区间、上限和风险。
3. **交易计划**：建仓、加仓、暂停、减仓、退出条件和证据要求。
4. **风险地图**：公司、行业、产业链、宏观、政策、商品、汇率、客户和融资暴露。
5. **交易记录模板**：理由、假设、估值、费用、失效条件和复核日。
6. **跟踪与交接**：指标、阈值、现金、下次复核和回写上游研究的事项。

## 质量控制

- 没有基准日、价格日期和来源时，不给“当前仓位建议”。
- 高权重必须有更强证据、更大安全边际、更低共同风险和明确失效条件。
- 组合数量、行业权重和止损比例不是普适真理，说明其与目标、波动和相关性的关系。
- 把行业、公司、价格和组合适配作为四个检查点，并与总流程交接卡保持一致。
